## 📌 Project Overview
Employee turnover is a costly challenge for any organization. This project develops an intelligent system to analyze the **IBM HR Analytics dataset**, identifying why employees leave and providing a proactive **Decision Support System** to enhance retention and performance.

## 🎯 Core Objectives
*   **🔍 Attrition Prediction:** Developing a classification model to detect high-risk employees before they leave.
*   **👥 Employee Segmentation:** Applying **K-Means Clustering** to segment the workforce based on performance and engagement levels.
*   **💡 Strategic Insights:** Providing data-backed recommendations for HR policy optimization.

## 🚀 Key Features & Pipeline
1.  **Data Ingestion:** Efficiently processed **1,470 records** from the **IBM HR Analytics** dataset[cite: 3].
2.  **Explورatory Data Analysis (EDA):**
    *   Determined the global **Attrition Rate (~16.12%)**[cite: 3].
    *   Mapped correlations between income, department, and turnover[cite: 3].
3.  **Feature Engineering:**
    *   Categorical Encoding for non-numeric data[cite: 3].
    *   Creation of custom **Engagement & Performance Indicators**[cite: 3].
4.  **Advanced Modeling:**
    *   **Classification:** Attrition Risk Prediction[cite: 3].
    *   **Clustering:** Professional Segmentation using **K-Means**[cite: 3].

---

## 📈 Initial Key Insights
> *Our analysis has already uncovered critical trends:*

*   **💸 The Salary Factor:** Employees who left had a significantly lower **Monthly Income** than their peers[cite: 3].
*   **🏢 Department Risk:** The **Sales** and **Research & Development** departments exhibit the highest turnover volatility[cite: 3].
*   **📉 Performance Correlation:** Early data suggests a link between lower performance ratings and increased attrition risk[cite: 3].
