AI-Powered HR Analytics System 🚀
Project Overview
This project aims to develop an intelligent system for employee analytics and decision support. By analyzing the IBM HR Analytics dataset, we identify key factors contributing to employee attrition and provide data-driven strategies to improve retention and performance. 
Objectives
•	Attrition Prediction: Build a classification model to identify employees at high risk of leaving. 
•	Employee Segmentation: Use clustering techniques to segment employees based on performance and engagement. 
•	Strategic Insights: Recommend HR strategies to optimize workplace stability. 
Key Features & Steps
1.	Data Ingestion: Processed the HR-Employee-Attrition.csv dataset (1,470 records). 
2.	Exploratory Data Analysis (EDA):
o	Analyzed attrition distribution (Overall rate: ~16.12%). 
o	Identified correlations between Monthly Income, Department, and turnover. 
3.	Feature Engineering: Encoding categorical variables and creating engagement indicators. 
4.	Modeling (In Progress):
o	Attrition Prediction (Classification). 
o	Employee Segmentation using K-Means. 
Initial Insights
•	Salary Impact: Employees who left the company had a significantly lower average Monthly Income compared to those who stayed. 
•	Departmental Trends: High attrition rates were observed in the Sales and Research & Development departments. 
Technologies Used
•	Language: Python
•	Analysis: Pandas, NumPy
•	Visualization: Matplotlib, Seaborn
•	Cloud Environment: Databricks (Recommended) 
Dataset Source
•	IBM HR Analytics (Kaggle).
